# OnCo AI Solver

## v1.2.0 baseline

This repository stores the v1.2.0 Chrome/Whale extension source with Gemini, OpenAI API, and experimental ChatGPT sign-in integration.

Load `extension/` as an unpacked browser extension. See `bridge_legacy/README_KO.md` for the original local login helper requirements.

**Security:** Do not commit API keys, cookies, access tokens, or user-specific settings. ChatGPT subscription access is subject to official account authorization, and has not been verified with a real account.

Version 1.3.0 installer/native-messaging refactoring is developed separately in a pull request.
