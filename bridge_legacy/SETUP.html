OnCo AI Solver · ChatGPT 계정 로그인

공식 OpenAI Sign in with ChatGPT 인증을 사용하는 개인용 로컬 연결 기능입니다. Chrome 확장 프로그램은 PC에서 인증 콜백을 수신할 수 없으므로, PC에서 실행되는 작은 도우미가 필요합니다.

처음 설치하기 (Windows)

  1. Node.js 공식 홈페이지에서 Node.js 22 이상을 설치합니다.
  2. ZIP을 압축 해제한 폴더의 chatgpt_bridge 하위 폴더에서 start_windows.cmd를 실행합니다. PC와 모바일에서 파일을 실행하는 환경이 다를 수 있습니다.
  3. 열린 검은 콘솔 창의 12자리 연결 코드를 확장 프로그램 → ChatGPT 계정 로그인 → 연결 코드 칸에 입력합니다.
  4. Continue with ChatGPT 버튼을 누르면 공식 OpenAI 로그인 페이지가 열립니다. 로그인·워크스페이스 선택·사용량 공유 권한 승인까지 진행합니다.
  5. 다시 확장 프로그램 팝업을 열면, 로그인된 계정의 GPT 모델이 자동 표시됩니다.

평소 사용하기

ChatGPT 방식 사용 중에는 start_windows.cmd 콘솔 창을 열어 두세요. 도우미를 재시작하면 연결 코드 입력과 ChatGPT 계정 재로그인이 필요합니다. Gemini/OpenAI API 키 방식에는 도우미가 필요 없습니다.

보안 · 비용

연결 코드는 PC 안의 127.0.0.1:18744에서 확장 프로그램과 도우미를 연결하는 용도이며, ChatGPT 비밀번호를 입력받지 않습니다. OAuth 접근/갱신 토큰은 도우미 메모리에만 남고 종료하면 사라집니다. 호스트 ID와 발급된 OAuth 클라이언트 ID는 사용자 홈 폴더의 .onco-ai-solver/chatgpt-registration.json에 보관합니다.

ChatGPT 계정에서 플랜 사용 권한을 명시적으로 허용해야 모델 호출이 가능하며, 계정의 요금제·사용 한도·허용된 모델에 따라 이용이 제한될 수 있습니다. 사용량은 ChatGPT 사용량 설정에서 확인할 수 있습니다.

OpenAI API 키 방식은 위 로그인 방식과 무관하며, OpenAI API 키 발급 페이지에서 생성한 키를 사용합니다. API 사용 요금은 ChatGPT 구독과 별개입니다.

참고: 공식 로그인 문서 Sign in with ChatGPT — OSS registration and sign-in. 개인/로컬 사용 목적으로 제공되며, 실제 계정 로그인은 사용자가 직접 수행해야 합니다.
