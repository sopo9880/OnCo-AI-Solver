🧩 OnCo AI Solver v1.3.3

최초 한 번만 브라우저 확장 프로그램을 등록하세요. 이후에는 OnCo 문제 화면에서 자동으로 동작합니다.

1확장 관리 화면 열기

Google Chrome

설치된 Chrome에서 확장 프로그램 관리 화면 열기

chrome://extensions
새 탭에서 열기
Naver Whale

설치된 Whale에서 확장 프로그램 관리 화면 열기

whale://extensions
새 탭에서 열기

최초 실행 시 'OnCo AI Solver 열기' 같은 외부 앱 실행 확인창이 나타날 수 있습니다. 허용하면 선택한 브라우저의 새 탭이 열립니다. 작동하지 않거나 해당 브라우저가 설치되지 않았다면 주소 복사를 눌러 브라우저 주소창에 붙여넣으세요.

2개발자 모드 켜기

① 확장 프로그램 관리 화면에서 개발자 모드를 켜짐으로 설정
② 압축해제된 확장 프로그램 로드 클릭
③ 아래 설치 폴더의 extension 선택

웹스토어에 게시하지 않은 개인용 확장이므로 사용자 승인이 필요합니다.

3OnCo 확장 프로그램 폴더 지정

선택할 폴더 (설치 경로를 변경했다면 설치한 위치의 extension 폴더 선택):

설치 경로를 바꾼 경우 Windows 시작 메뉴의 OnCo 확장 프로그램 폴더에서 폴더를 열 수 있습니다.

4연결 확인 및 ChatGPT 로그인

브라우저 도구 모음의 OnCo AI Solver 아이콘을 눌러 ChatGPT 계정 로그인 선택 → Continue with ChatGPT 클릭. 공식 로그인 페이지에서 먼저 기본 계정 로그인을 진행하세요.

로그인과 ChatGPT 구독 사용 권한은 별도입니다. 구독 사용 권한이 없으면 오류가 표시되며 OpenAI API 키로 자동 과금 전환하지 않습니다.

로그인 후 팝업을 다시 열어 계정 로그인과 GPT 사용 권한을 각각 확인하세요. 플랜을 사용하려면 별도 GPT 플랜 사용 권한 요청 버튼을 눌러 동의합니다. 기존 플랜 사용 동의가 유효하다면 다시 승인할 필요가 없습니다. 그 뒤 모델 목록 새로고침을 누르세요.

5평소 사용 및 업데이트

OnCo의 실제 문제 내용과 코드 에디터가 모두 로딩된 화면에서만 복사·풀이 버튼이 뜹니다. 일반 홈·공지사항·강의 화면에서는 표시되지 않습니다.

업데이트: 새 Setup 실행 → 위의 '새 탭에서 열기' 버튼으로 브라우저 확장 관리 열기 → 설치된 OnCo 확장에서 새로고침(↻). 설치 경로를 유지하면 설정은 보존됩니다.
